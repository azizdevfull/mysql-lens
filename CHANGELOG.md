# Changelog

## 0.1.0

First release.

- Unlimited MySQL / MariaDB connections with SSH tunnels, SSL and a read-only mode.
- Table editor with a query box, SQL autocomplete, inline editing and transactional saves.
- SQL editor integration with per-editor sessions, a results grid and query cancellation.
- Export to CSV, TSV, Excel, JSON, SQL and Markdown; SQL dump (`.sql` and `.sql.gz`).
- Import of SQL files and of CSV, JSON and Excel data.
